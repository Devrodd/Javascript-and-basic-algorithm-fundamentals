# JavaScript Fundamentals 🚀

Repositório criado para documentar minha evolução nos estudos de **JavaScript**, explorando os fundamentos da linguagem e construindo uma base sólida para desenvolvimento Web.

O objetivo deste projeto é praticar conceitos essenciais da programação, aplicando lógica, estruturas de controle e manipulação de dados através de pequenos exercícios e desafios.

## 📚 Conteúdos estudados

### ✅ Tipos de Dados

* Strings
* Numbers
* Boolean
* Undefined
* Null
* Conversão de tipos

### ✅ Operadores

* Operadores aritméticos
* Operadores de atribuição
* Operadores de comparação
* Operadores lógicos

### ✅ Estruturas de Controle

* Condicionais (`if`, `else`, `switch`)
* Laços de repetição:

  * `for`
  * `while`
  * `do...while`
* Controle de fluxo:

  * `break`

### ✅ Strings

* Manipulação de textos
* Métodos de strings
* Interpolação de valores

### ✅ Arrays

* Criação e manipulação de arrays
* Percorrer listas
* Busca e operações com elementos
